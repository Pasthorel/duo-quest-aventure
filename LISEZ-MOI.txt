DUO QUEST V6 — CORRECTIF VISUEL ET FONCTIONNEL

Dans le refuge, les éléments sont désormais dessinés dans une vraie scène 2.5D : murs, lit, sol, décorations, plantes, fenêtre et éclairages changent visiblement. Les boutons allument / éteignent la lampe et activent la nuit. L’album applique les thèmes sur les pages complètes ; le choix du thème se voit immédiatement dans l’éditeur, et un bouton permet d’appliquer le thème actif à toutes les pages.

PUBLICATION : décompresser, puis téléverser TOUS les fichiers directement à la racine du dépôt GitHub Pages, en remplaçant les fichiers de même nom. Ne pas téléverser seulement le ZIP.

SAUVEGARDE : exporter votre progression ET vos photos avant remplacement. Les données restent locales sur le téléphone. V6 conserve les clés de sauvegarde V4/V5. Ne supprimez pas les données du site Safari.

TEST : tester l’allumage de lampe, le changement de lit et murs, puis l’éditeur photo et le changement de thème. Les illustrations des fonds font partie des fichiers à transférer.

LIMITES : la chambre est une composition 2D avec perspective (2.5D), et non un véritable environnement 3D. La position des meubles est fixée par type pour cette version.
