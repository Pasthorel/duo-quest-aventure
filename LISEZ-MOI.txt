DUO QUEST — VERSION 1.0
======================
Application PWA gratuite pour un iPhone, sans compte et sans serveur de progression.

INSTALLATION SUR IPHONE
1. Héberger le contenu de CE dossier sur une URL HTTPS gratuite (par exemple GitHub Pages ou Cloudflare Pages). Il faut publier les fichiers contenus dans ce dossier, pas simplement envoyer le ZIP à Safari.
2. Ouvrir cette URL dans Safari sur l'iPhone, avec Internet la première fois.
3. Menu Partager > Sur l'écran d'accueil > Ajouter (activer Ouvrir comme app si proposé).
4. Ouvrir Duo Quest depuis l'icône. Ensuite, après mise en cache, l'app fonctionne hors ligne. Les liens externes vers Plans demandent du réseau.
5. Dans « Nous » > « Exporter notre aventure », sauvegarder régulièrement le fichier JSON dans Fichiers/iCloud. Pour restaurer, importer le fichier.

APERÇU SUR ORDINATEUR
Ouvrir index.html directement permet une visualisation et les quêtes, mais le mode hors ligne et l'installation PWA nécessitent une origine HTTPS (ou localhost). Pour tester localement sur un PC : python -m http.server 8000, puis http://localhost:8000.

PRIVÉ
Le code de l'application est hébergé publiquement si l'on choisit GitHub Pages public, MAIS les données de progression restent dans l'appareil. Aucun compte ou synchronisation. Les liens Plans sont volontaires.

IMPORTANT
- Les étapes de quêtes sont validées manuellement. Pas de GPS / surveillance automatique.
- Les activités payantes, les déplacements et les conditions d'accès sont à vérifier. Certains espaces ferment selon la saison.
- N'effacez pas les données Safari ou l'app sans exporter : cela peut effacer la progression.
- Les fichiers peuvent être hébergés sans frais sur une offre gratuite, dans les limites de son service.
- Les titres, quêtes et secrets sont dans le code : pour rester sans spoiler, ne lisez pas app.js !
