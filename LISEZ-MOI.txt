DUO QUEST — V2 Angèle & Adrien
=================================

Cette version met à jour l'application avec :
- le duo par défaut « Angèle & Adrien » ;
- une direction artistique renforcée, toujours inspirée du prototype validé ;
- davantage de quêtes, de badges et de petites fonctionnalités locales.

POUR METTRE À JOUR LE SITE GITHUB PAGES
---------------------------------------
1. Décompressez ce ZIP.
2. Ouvrez votre dépôt GitHub « duo-quest-aventure ».
3. Supprimez ou remplacez les anciens fichiers par ceux du dossier duo-quest/.
4. Vérifiez qu'index.html, app.js, style.css, manifest.webmanifest, sw.js et le dossier icons/ sont à la racine du dépôt.
5. Validez les changements (Commit changes).
6. Attendez 1 à 3 minutes puis rechargez votre site GitHub Pages.

IMPORTANT
---------
- Si votre iPhone garde l'ancienne version, fermez l'app puis rechargez le site une fois dans Safari.
- Vous pouvez aussi supprimer l'icône d'écran d'accueil et la remettre après mise à jour.
- Vos données sont locales à l'appareil, pensez à exporter la sauvegarde depuis les réglages.
